# 99Bricks — Jaipur Property Map

A map-based real estate listing platform for Jaipur, India. Built with Next.js, React, TypeScript, Tailwind CSS, Supabase, and Mapbox.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project auto-deploys via Vercel's GitHub integration: every push to the `main` branch is built and, if the build succeeds, deployed to production automatically. There is no manual deploy step.

- Production: https://jaipur-property-map.vercel.app
- Repository: https://github.com/sumit-jaipur/jaipur-property-map

Database schema changes (SQL migrations) are run manually in the Supabase SQL Editor and are never applied automatically.
